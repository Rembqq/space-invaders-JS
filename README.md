**Space Invaders (JS) — README**

Space Invaders це мінімалістична версія Space Invaders на чистому HTML + JavaScript (Canvas). Гра складається з одного файлу index.html і запускається простим відкриттям його в браузері. Проєкт ідеальний як навчальний прототип — легко змінювати фізику, поведінку ворогів і додавати нові механіки.

**Швидкий старт**

Скопіюй index.html (весь HTML+CSS+JS в одному файлі) у папку.
Відкрий index.html у сучасному браузері (Chrome/Firefox/Edge/Safari).
Гра стартує автоматично.

_Контролі_

← / A — рух вліво

→ / D — рух вправо

Space — стріляти

Кнопка Restart на екрані — перезапуск гри
